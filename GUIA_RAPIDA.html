De ZIP a sistema funcionando.

No necesitas instalar paquetes npm ni configurar un servidor de base de datos.

01

Extrae la carpeta completa

Clic derecho en el ZIP → Extraer todo. Abre la carpeta PASO-ERP. Puedes guardarla en Documentos o en otra ubicación propia.

02

Instala Node.js

Descarga una versión LTS 22.14 o posterior desde nodejs.org. Conserva la opción de agregar Node al PATH. SQLite viene integrado.

03

Abre la terminal

Dentro de la carpeta, ejecuta npm run diagnostico y npm start. Conserva la terminal abierta y entra a http://127.0.0.1:3100.

La primera ejecución prepara los datos iniciales de la tienda. Para detener el servidor, pulsa Ctrl+C. Al volver a iniciar, tus operaciones se conservan.

Un recorrido para probarlo de verdad.

Ejercicio de 15–20 minutos. Sigue el orden con una variante nueva para comprobar los resultados.

  1. Entra como administrador y revisa la caja.

    Debe existir una caja de hoy abierta. Si quedó una de otro día, ciérrala y abre la actual.

  2. Crea PASO “Campus”, talla 40, azul.

    SKU PASO-CAMPUS-40-AZUL · costo S/ 90 · precio S/ 150 · stock inicial 5 · mínimo 2. En una repetición, usa otro SKU.

  3. Compra 3 pares y confirma su recepción.

    Total S/ 270. Antes de recibir, stock 5. Después de recibir, stock 8. Revisa el movimiento de entrada.

  4. Entra como vendedor y vende 2 pares en efectivo.

    Total S/ 300. El stock baja a 6 y la caja aumenta S/ 300. Consulta la constancia e intenta imprimirla o guardarla como PDF.

  5. Registra un egreso de S/ 20 y cierra caja.

    El esperado disminuye S/ 20. Ingresa el importe esperado como efectivo contado: la diferencia debe ser S/ 0.

  6. Entra como almacén y registra un ajuste de −1.

    Escribe un motivo. El stock final del ejercicio será 5. Observa que este rol no tiene acceso a ventas, caja ni reportes.

  7. Regresa como administrador a los reportes.

    Filtra la fecha de hoy. El producto del ejemplo registra 2 pares, S/ 300 de ventas y S/ 120 de margen bruto. Prueba la exportación CSV.

Compra → recepción → inventario (+)
Venta → inventario (−) → constancia → caja si es efectivo
Caja: fondo + ingresos − egresos → cierre y diferencia → reportes.

Tarjeta y transferencia se registran como medios de pago; no ejecutan cobros reales ni aumentan el efectivo físico. Las constancias son internas, sin valor tributario.

Puerto ocupadoComprueba si ya está abierto el ERP. Para usar otro puerto, aplica el ejemplo de consola que aparece debajo.

Faltan archivos o no guarda datosExtrae todo el ZIP a una carpeta propia con permiso de escritura.
SQLite muestra ExperimentalWarningEn Node 22.14 es un aviso. Si aparece la dirección del servidor, puede continuar el uso.

Alternativa desde PowerShell, dentro de la carpeta del sistema, para usar el puerto 3101:

$env:PORT = '3101'
node server/server.mjs

Luego abre http://127.0.0.1:3101. La dirección local se utiliza en la misma PC que ejecuta el servidor; las instalaciones no sincronizan datos entre sí.

Edita el código con tu equipo.

Abre toda la carpeta en tu editor. Edita las pantallas y estilos en public/, las reglas y API en server/ y las pruebas en tests/.

npm run dev

El servidor reinicia al cambiar el backend. Guarda y recarga el navegador para ver cambios en la interfaz. Antes de compartir, ejecuta npm run check y npm test. Consulta docs/DESARROLLO.md para colaborar con el código fuente.
